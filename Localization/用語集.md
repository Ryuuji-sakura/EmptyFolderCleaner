# 翻訳の用語集（空フォルダ削除）

2026-11-13 作成。インドネシア語(id)・マレー語(ms)・韓国語(ko)・デンマーク語(da)・タイ語(th)・繁体中国語 台湾(zh-Hant)・
簡体中国語(zh-Hans)・ドイツ語(de)・スペイン語(es)・フランス語(fr)・ベトナム語(vi)・ヒンディー語(hi) を足すときの決まり。
コートポン！の `用語集.md` と同じ12言語の並び。アプリ名と用語は Grok に相談した結果を元にした（採用・不採用は PROGRESS.md）。

## アプリの説明（訳す人への前提）

Mac の無料ユーティリティ。フォルダをドラッグ＆ドロップすると、中身が空のフォルダを探して一覧にし、
選んだものを **ゴミ箱（既定）** か **完全削除** で消す。Finder が自動で作る見えない設定ファイル `.DS_Store` だけが
残っているフォルダも「空」とみなして消せる。画面は小さなウィンドウで、ボタンやチェック欄の文は**短く**訳す。

## 全言語に共通の決まり

1. **書式指定子（`%@`, `%lld`, `%1$@` など）は、種類と数をそのまま残す。** 語順に合わせて位置を変えてよい。
   同じ種類が2つ以上あって順番を入れ替えたいときは `%1$@` / `%2$@` の番号付きにする（キー「%lld 件中 %lld 件を選択」は
   英訳が `%2$lld of %1$lld selected`。1番目が全体の件数、2番目が選んだ件数）。
2. **英訳（en）の意味に忠実に。** 長さも英訳に近づける。ボタンやチェック欄は英語より長くしない工夫をする。
3. **文を組み立てる部品がある。** 画面の文は、次の部品を `%@` に埋めて作る。部品の訳は**名詞句**として単独で自然にする。
   - 「空フォルダ %lld 件」「.DS_Store %lld 個」＝名詞句（例 en: "3 empty folders" / "1 .DS_Store file"）。複数形の項目。
   - 「%@、%@」＝名詞句を2つ繋ぐ（en: "%1$@ and %2$@"）。その言語の「と」「および」に当たる繋ぎにする。
   - 「%@が見つかりました。」「%@をゴミ箱に入れました。」「%@を完全に削除しました。」などの `%@` には、その名詞句が入る
     （1つか、上の繋ぎで2つ）。**語順・格変化・性数一致が破綻しない**ように、名詞句を主語・目的語として自然に置く。
   - 「、」＝失敗したファイル名を並べるときの区切り（en: ", "）。その言語の読点か区切りにする。末尾の空白も英訳どおり。
   - 文と文は、アプリ側が**半角スペース1つ**で繋いで並べる。文末は句点・ピリオドで終える。
   - **名詞句の数・性が変わっても文が崩れないようにする（重要）。** `%@` には「3 empty folders」「1 .DS_Store file」のように、
     単数・複数・男性・女性が混じる名詞句が入る。動詞や過去分詞が名詞句の数・性に一致する言語（de, es, fr, hi など）は、
     「…が見つかりました」の形に訳すと、片方で崩れる。**「ラベル: %@」の形（コロンで名詞句を後ろに置く）か、
     数・性に左右されない言い方にする。** 例: de "Gefunden: %@." / es "Encontrado: %@." / fr "Trouvé : %@." /
     hi "मिला: %@।"。ko は名詞句がどちらも「〜개」で終わる前提で目的格は 를 に固定してよい（「빈 폴더 3개」「.DS_Store 1개」）。
     助詞や格変化が名詞句の形で変わる言語は、名詞句を「は／が」と「を」の両方に使っても崩れない語順にする。
4. **ボタン名を引用している文は、そのボタン自身の訳と完全に同じ語にする。** 例: 「もう一度調べる」「中止」「フォルダを選択」
   「ゴミ箱に入れる」「削除したものをゴミ箱に入れる」「完全に削除する」「スキャン中... %@ 項目」。引用符はその言語の普通のもの
   （en は “ ”、zh-Hant は「」、zh-Hans は “ ”、de は „ “、fr は « » など）。
5. **アプリ名**は下の「アプリ名」の表のとおり。キー「空フォルダ削除」「空フォルダ削除の使いかた」「使いかた」の訳に使う。
6. **「Finder」「.DS_Store」は訳さない**（そのまま書く）。「ゴミ箱」は macOS がその言語で使っている語に合わせる（下の表）。
   「元に戻す」は macOS の Finder の語（"Put Back"）に合わせる。
7. 呼びかけは命令形か主語なし。丁寧すぎず、くだけすぎない。`…`（三点リーダー）は `…` のまま残す。
8. 英訳に末尾の空白・改行・引用符の種類などの指定があれば守る。

## アプリ名（Dock・メニューバー・ヘルプの表題）

Grok に相談して決めた（2026-11-13）。方針は、App Store の検索で現地の人が打つ言葉（「空フォルダ 削除」に当たる語）を
名前に入れること。例外は2つ：hi は英語名のまま（インドでは英語のアプリ名が一般的）、fr は Grok の「Dossiers vides」を
動詞が無く機能が伝わりにくいので「Supprimer les dossiers vides」に直した。en は「Empty Folder Sweeper」（変更しない）。

キー「使いかた」は、それを短くしたもの（メニュー項目）。

## 言語ごとの決まり

- **id（インドネシア語）**: 主語なしの命令形（"Pilih folder"）。代名詞が要るときだけ "Anda"、"kamu" は使わない。フォルダは "folder"、ファイルは "berkas"、ゴミ箱は macOS の "Sampah"。
- **ms（マレー語）**: 主語なしの命令形。代名詞が要るときは "anda"。id の訳をそのまま流用しない（ファイルは "fail"、ゴミ箱は "Tong Sampah"、削除は "padam"）。
- **ko（韓国語）**: 文は 해요체（〜합니다 の硬さにしない）。ボタンは名詞か短い動詞（삭제, 중단）。フォルダは "폴더"、ファイルは "파일"。
- **da（デンマーク語）**: 命令形か名詞形（"Vælg mappe"）。"du" は避ける。フォルダは macOS の語 "mappe"、ファイルは "fil"、ゴミ箱は "Papirkurv"。
- **th（タイ語）**: 丁寧語の文末（ครับ/ค่ะ）は付けない。単語は区切らず、句の切れ目にだけ空白を入れる。フォルダは "โฟลเดอร์"、ファイルは "ไฟล์"。
- **zh-Hant（台湾の繁体字）**: 台湾の語（資料夾、檔案、垃圾桶）。引用符は「」。句読点は全角（，。）。件数は「個」「項」など自然な助数詞。
- **zh-Hans（簡体字）**: 本土の語（文件夹、文件、废纸篓）。引用符は “ ”。句読点は全角（，。）。zh-Hant の訳を字体だけ変えて流用しない。
- **de（ドイツ語）**: ボタンは命令形（"Ordner auswählen"）、文は主語なしか受動。"Sie" は避ける。macOS の語（Ordner、Papierkorb、Ablage 等）。引用符は „ “。名詞句は格を考えて、「%@ wurde(n) …」のような語順にしない（%@ は常に完全な名詞句）。
- **es（スペイン語）**: 中立的なスペイン語。ボタンは不定詞か命令形（"Elegir carpeta"）。"tú/usted" の代名詞を避ける。macOS の語（carpeta, Papelera, archivo）。引用符は « »。複数形は one / many / other の3区分すべてを書く（many は100万などの大きな数用で、other と同じ語形でよい。空にしない）。
- **fr（フランス語）**: ボタンは不定詞（"Choisir un dossier"）。"vous" の命令形は文の中で最小限に。macOS の語（dossier, Corbeille, fichier）。引用符は « »（内側に半角の空白）。複数形は one（0・1）/ many / other の3区分を書く（many は other と同じ語形でよい。空にしない）。
- **vi（ベトナム語）**: "bạn" はなるべく使わず、命令形・短い句。フォルダは "thư mục"、ファイルは "tệp"、ゴミ箱は macOS の "Thùng rác"。
- **hi（ヒンディー語）**: デーヴァナーガリーで書く。フォルダは "फ़ोल्डर"、ファイルは "फ़ाइल"、ゴミ箱は macOS の "रद्दी"（Apple のヒンディー語ガイドで確認、移動は "मूव करें"、元に戻すは "वापस रखें"）。"Finder" と ".DS_Store" は英字のまま。数字はアラビア数字（0-9）。
